# Local — Виртуальный журнал-каталог (HTML/CSS/JS)

## Запуск
Самый простой способ:
- Откройте `index.html` двойным кликом (если браузер не блокирует локальные файлы), или
- Запустите локальный сервер (рекомендуется):

### Вариант A: VS Code Live Server
1) Откройте папку проекта в VS Code
2) Установите расширение **Live Server**
3) Нажмите **Go Live**

### Вариант B: Python
В терминале внутри папки проекта:
```bash
python -m http.server 8000
```
Откройте в браузере: http://localhost:8000

## Как редактировать каталог
Откройте `js/app.js` и найдите объект `CATALOG`.

- `brandName`, `brandTag`, `shopUrl` — имя магазина, подпись, ссылка.
- `pages` — массив страниц.

### Страница (layout)
Страница состоит из:
- `title` (текст, позиция, размер)
- `subtitle` (опционально)
- `elements` — элементы:
  - `{ type: "image", src, x, y, w, h }`
  - `{ type: "text", text, x, y, size }`
  - `{ type: "line", x, y, w }`

> Координаты `x/y/w/h` задаются в процентах от страницы (0..100), это удобно для точной верстки “как в PDF”.

## Папка с изображениями
Кладите изображения в `assets/` и используйте путь вроде `assets/my-page.jpg`.
